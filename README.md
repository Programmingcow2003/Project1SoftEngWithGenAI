# Project1SoftEngWithGenAI

This project includes includes everything needed to run. Part 1 includes the notebooks which were used to train the LLMs. Also included are the two trained LLMs tokenizers and losses. The ckpts are too large and are sent separately in an email.

Part 2 and three and four include everything needed, the only modification which must be made is uploading the checkpoint and tokenizer and setting the path to include its location.

To run these, just run all the cells in Google Colab. Make sure you had a Github connected so you can pull the repositories used during this project.

If you want to run my files there is a notebook in the Models folder. Note you must upload a checkpoint and give it the file path
